# Учебный проект: Интернет-магазин (Django)

Проект интернет-магазина, разрабатываемый в рамках учебного курса. Код будет постепенно дополняться новым функционалом от урока к уроку.

Текущий статус: Настроена связь с БД PostgreSQL (Задание 23).

Задание 22:

- Добавлено приложение catalog.

- Реализованы главная и контактная страницы с базовыми шаблонами на Bootstrap.

- Настроена маршрутизация.

Задание 23:

- Созданы модели Product и Category
- Созданы и применены миграции моделей в базу данных
- Настроено отображение моделей на панели администратора
- База заполнена тестовыми примерами и из них сделаны файлы фикстур

- Создана кастомная команда для добавления продуктов из фикстур
